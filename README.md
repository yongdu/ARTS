# ARTS

This is a log book to record a coder growth — one entry every week.

- **A**gent
Build, run, or take apart one AI agent thing per week: a small agent, a tool/MCP server, a prompt or eval pattern, or a dive into an agent framework. Show the code and what you learned from it.
- **R**eview
Review a technical article, paper, or blog and leave a comment
- **T**ip
Learn a technical skill to facilitate development
- **S**hare
Share a view or opinion towards new technique or self reflect (can be lesson learned from project)

## Layout

```
YYYYwNNARTS.md   weekly entry (ISO week), e.g. 2026w46ARTS.md
TEMPLATE.md      copy this to start a new week
Agent/           longer write-ups and code for the Agent section
Review/          longer reviews
Tip/             longer tips
Share/           longer shares
```

Keep the weekly file short. If a section grows beyond a few paragraphs, put it in its folder as `YYYYwNN<Topic>.md` (e.g. `Agent/2026w46ToolCallingLoop.md`) and link it from the weekly file.

## Start a new week

```sh
cp TEMPLATE.md "$(date +%Gw%V)ARTS.md"
```
